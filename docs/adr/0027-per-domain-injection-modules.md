# ADR-0027 — 按域分注入模块与新注入模块准入三判据

状态：accepted（grill 定稿）
日期：2026-09-25
决策来源：D-091（export_scene Maya 侧落位裁决）；佐证：D-090（注入体积预算）、D-044（冻结棘轮纪律）

## 背景

maya_scene_module.py 4583 行巨石，mypy 冻结基线 237 条中 183 条住它，T-07 拆分已挂号。issue #5 的 scene_export 需要新增 Maya 侧能力，落位问题确立先例——此前 _mcp_scene（场景域）、_mcp_visual（视觉域）、_mcp_asset（资产域）已三次验证 per-domain 注入模块形态，共用件 ensure_module_injected 于 T-22a 提炼完毕。

## 决策

- **新 Maya 侧能力默认新建独立注入模块，不进巨石。**域边界=注入边界：文件粒度=注入粒度=失败域粒度。
- **注入模块准入三判据**（全部满足才允许新建，防先例滑梯）：
  1. 独立注入时机——懒注入触发点自成节拍，不与其他模块同生共死
  2. 独立 Maya 侧 API 面——cmds/omui 调用面与既有模块正交
  3. 独立失败域——异常/降级语义不与他模块共享
- 跨注入模块调用须显式声明（注入模块自包含是架构约束；visual_module 同型代码不共享即此约束的代价侧）。
- scene_export 落地形态：export_module.py→_mcp_export（懒注入，首个 export 调用触发，复用 ensure_module_injected）+ export_tools.py 宿主侧注册。

## 被否选项

- **并入 maya_scene_module**：棘轮恶化（新函数产生的 mypy 新错只能抬高冻结预算）+ T-07 搬运面扩大 + review 冲突面扩大，三杆同向恶化。
- **巨石内 section 标记区**：同上弱化版，物理上仍同文件同注入同失败域。
- **「语义就近」落位**（对场景做事→放场景模块）：本仓域边界已由注入边界定义，asset 同样「对场景做事」仍独立成模块为先例。

## 后果

- 判据是显式门槛：不满足三判据的能力进既有模块（并说明归属理由），满足才立新模块；不许以「巨石太大不方便」为由单独开模块。
- 注入体积是预算资源（native 通道 15000B 阈值）——模块内行数=成本，最小原语抽取（D-090 的 _delete_if_exists）是对冲姿势。
- stub 层随新域扩张（cmds.file 导出面按 D-074 先例补齐）。
- AGENTS.md 承载判据的执行条款（联动规范），本 ADR 承载决策与理由。
